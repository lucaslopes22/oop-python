# Estudo de Programação Orientada a Objetos com Python

Bem-vindo ao meu repositório de estudo! 🎉 

Este projeto reflete meu estudo contínuo e aprofundado sobre **Programação Orientada a Objetos (POO)** utilizando a linguagem **Python**. Através dele, estou explorando e aplicando conceitos fundamentais da POO em diversos contextos, buscando dominar essa poderosa metodologia de desenvolvimento de software.

---

## 🚀 Objetivos do Projeto

- **Compreensão da POO**: Aprender e aplicar os principais conceitos da programação orientada a objetos, como **classes**, **objetos**, **herança**, **polimorfismo**, **encapsulamento** e **abstração**.
- **Prática com Python**: Desenvolver habilidades em Python para implementar soluções baseadas nesses princípios.
- **Desenvolvimento Contínuo**: O projeto é uma evolução constante, com novos desafios sendo adicionados à medida que o aprendizado avança.

---

## 📚 Conceitos Abordados

Aqui estão alguns dos principais tópicos que estou explorando:

- **Classes e Objetos**: Como criar e instanciar objetos em Python.
- **Herança**: Estendendo classes e reutilizando código.
- **Polimorfismo**: Utilizando métodos com o mesmo nome, mas com comportamentos diferentes.
- **Encapsulamento**: Protegendo dados e criando interfaces limpas.
- **Abstração**: Simplificando a complexidade do sistema, focando apenas no essencial.

---

## 🔧 Como Rodar o Projeto

1. **Clone este repositório:**

    ```bash
    git clone https://github.com/lucaslopes22/oop-python.git
    ```

2. **Entre no diretório do projeto:**

    ```bash
    cd oop-python
    ```

3. **Execute os arquivos Python desejados:**

    ```bash
    python3 main.py
    ```
